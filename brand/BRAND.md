# Verify Everything brand kit

## Marks

| File | Use |
|---|---|
| `verify-everything-mark.svg` / `verify-everything-avatar-1024.png` | Org mark: the universal quantifier ∀ drawn as a checkmark. Read it as "for all, verified". Use the PNG as the org avatar. |
| `verified-libs-mark.svg` / `verified-libs-mark-1024.png` | verified-libs mark: a library package carrying the Verify Everything seal. |
| `verified-libs-social.svg` / `verified-libs-social-1280x640.png` | Social preview card for the verified-libs repo. Upload the PNG; the SVG depends on system fonts. |

## Colors

| Name | Hex | Use |
|---|---|---|
| Ink | `#0E1726` | Backgrounds |
| Mint | `#5EEAA8` | The mark, accents |
| Slate | `#C9D4E3` | Secondary strokes, light text |
| Muted | `#8E9DB3` | Body text on ink |

## Usage

- Keep the mark on ink, or mint on any background dark enough to keep contrast.
- Don't stretch, rotate or recolor the ∀✓ mark. Don't add a separate checkmark next to it; it already is one.
- Leave clear space around the mark of at least the width of its crossbar.

## Taglines

- ∀x. verified(x).
- Trust, but verify. Actually, skip the trust.
- The libraries that made it. Receipts included. (verified-libs)
